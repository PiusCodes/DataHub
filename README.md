# DataHub AI

DataHub AI is an open-source dataset marketplace inspired by Kaggle: public browsing, clear dataset metadata, quality signals, and optional uploader-controlled pricing.

Datasets are free by default; a dataset only becomes paid when the uploader sets a price. A separate payment provider can be added later for `checkout_required` purchases.

## Local Setup

```bash
npm install
npm run dev
```

## Verification

```bash
npm run build
```
